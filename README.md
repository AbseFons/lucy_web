# Tú y yo

Base inicial de la web de Absé y Lucy.

## Stack
- React
- Vite
- TypeScript
- Framer Motion
- Lucide React
- date-fns

## Ejecutar

```bash
npm install
npm run dev
```

## Incluido en esta base
- Pantalla de entrada "Lucy, tengo algo para ti."
- Paleta visual completa
- Mobile first
- Intro "Tú y yo"
- Capítulo 2016
- Sección de 2017 / 2018 / 2025 / 26-03-2026
- Momento especial del 14-05-2026
- Contador dinámico de relación
- Mensaje automático cada día 14
- Barra de progreso de lectura
- Respeto a prefers-reduced-motion
- Estructura preparada para fotos, videos, audio y backend futuro
